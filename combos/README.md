# Combos do AScan AgenT

Coloque aqui arquivos `.txt` no formato:

```
usuario:senha
usuario2:senha2
```

O app lista e baixa automaticamente esses arquivos pelo botao **GitHub**.

## Como adicionar

1. Neste repositorio, pasta `combos/`
2. Upload de um arquivo, ex: `meu_combo.txt`
3. No app: **GitHub** → escolha o arquivo

> Nao commit arquivos com dados sensiveis se o repo for publico.
