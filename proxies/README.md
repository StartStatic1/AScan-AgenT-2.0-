# Proxies offline

Coloque arquivos `.txt` aqui com um proxy por linha:

```
1.2.3.4:8080
http://5.6.7.8:3128
socks5://9.9.9.9:1080
```

No app Android:
- **Online** → baixa de ProxyScrape, jetkai, monosans, TheSpeedX, roosterkid, proxifly, hookzof, etc. (HTTP + SOCKS5)
- **Offline** → cola TXT do gerador ou use arquivos desta pasta (botão Repo)

No Python (AScan_AgenT.py), salve em:
`/sdcard/AScan_AgenT/proxys/`
