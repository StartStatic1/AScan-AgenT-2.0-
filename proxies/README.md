# Proxies offline

Coloque arquivos `.txt` aqui com um proxy por linha:

```
1.2.3.4:8080
http://5.6.7.8:3128
```

No app Android use o botão **Offline** e cole o conteúdo do TXT
(ou use **Online** para baixar listas da internet).

No Python (AScan_AgenT.py), salve o arquivo em:
`/sdcard/AScan_AgenT/proxys/`
